nhzterm — quick reference

SESSIONS
  Sessions persist headlessly. Closing the app does not kill a running build;
  reopening replays the last 5000 lines of scrollback.

LONG-PRESS  the terminal for: Copy, Paste, Open (links only), and More >
  (Open URL, Share, Refresh, Kill Process, Style, Keep Screen On, Help,
   Settings, Report Issue).

  Refresh  repaints a frozen view WITHOUT killing the session.
  Kill Process  kills the command in the foreground, not your shell.

EXTRA KEYS (bottom bar)
  Row 1: ESC TAB CTRL ALT HOME UP END
  Row 2: /  -  PGUP PGDN LEFT DOWN RIGHT
  CTRL and ALT latch: tap, then press the next key.

VOLUME KEYS (no hardware keyboard needed)
  Vol Down + key = Ctrl+key   (Vol Down + C = Ctrl-C)
  Vol Up + Q/K toggles the extra-keys row
  Vol Up + E Esc, T Tab, W/S/A/D arrows, L |, H ~, U _
  Vol Up + P PageUp, N PageDown, B word-back, F word-forward
  Vol Up + 1..0 = F1..F10

CTRL SHORTCUTS
  ^A line start   ^E line end   ^C interrupt  ^D EOF     ^Z suspend
  ^L clear        ^K cut-to-end ^U cut-to-start ^W cut-word ^R history search

LIMITS
  15 concurrent sessions, 5000 lines of scrollback each.
